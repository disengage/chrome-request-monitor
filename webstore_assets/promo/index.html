Network Request Monitor 01

Capture

Every request
on the active tab.

Completed requests are listed newest first, with a method badge and the full URL. The count in the title follows the list, and new requests appear while the popup stays open.

  • 01Clear Logs wipes this tab only
  • 02Closing the tab clears its log
  • 03Click a row to copy the URL

Kept in chrome.storage.local on your device.

Network Request Monitor 02

Quick filters

APIs, assets,
or errors.

Three chips under the search box swipe into a focused list, on top of whatever URL filter is already typed. Back returns to the full tab.

API Requests

XHR, WebSocket, and /api, /graphql, or /vN URLs.

Web Assets

Scripts, styles, images, fonts, media, and those file types.

Error (5xx,4xx)

Completed requests whose status is 400–599.

The list on the right is API Requests.

Network Request Monitor 03

Filter

Narrow the list
as you type.

The URL filter is live, and the title count updates with it. Recent searches stay on chips — click to apply, × to delete. The last search is restored only when it still matches.

  • 01Matches any part of the URL
  • 02Recent chips, apply or delete
  • 03Last search returns when it still matches

Kept in chrome.storage.local on your device.

Network Request Monitor 05

Copy

Click a row.
The URL is copied.

On the main list or inside a domain, one click copies the full URL. A toast confirms it. Back leaves the host and returns to every request on the tab.

  • 01Copies the full URL
  • 02Toast reads Copies!!!
  • 03Back returns to the main view

Kept in chrome.storage.local on your device.
