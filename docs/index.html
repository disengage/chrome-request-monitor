Network Request Monitor – Privacy Policy

Last updated: November 2, 2026

Network Request Monitor stores everything it records locally in your browser. It does not send your data to the developer, sell it, or share it with analytics or advertising services.

What the extension does

Network Request Monitor is a developer tool that records the network requests made by each browser tab and lists them for the tab you are viewing. You can filter the list, copy request URLs, and see requests grouped by domain.

Data the extension handles

  • Request details: for each completed network request in a tab, the extension records the request URL, the HTTP method (such as GET or POST), the frame ID, and the ID of the tab. It does not read request or response bodies, headers, cookies, or form data.
  • Search keywords: the keywords you use to filter the list, so recent searches can be shown as shortcuts and your last search can be restored when you reopen the popup.

The extension does not collect personally identifiable information, and it does not inject scripts into the web pages you visit.

Where data is stored

All data is saved with chrome.storage.local on your device. It is not synced to your Google account and is not uploaded to any server operated by the developer.

How long data is kept

  • Requests for a tab are deleted when you close that tab.
  • You can delete the requests for the current tab at any time with Clear Logs.
  • Data for tabs that no longer exist is removed when a new browser window is opened.
  • Recent search keywords stay until you remove them from the popup. Your last search is discarded when it no longer matches any request.
  • Uninstalling the extension deletes all of its stored data.

Third-party services

To show website icons in the By Domain view, the popup loads favicons from Google's public favicon service (https://www.google.com/s2/favicons). This sends the domain name (for example, example.com) to Google, not the full URL. These requests are subject to the Google Privacy Policy. No other third-party services are used.

Permissions

  • webRequest – to see which network requests a tab has made.
  • storage – to save the request list and search keywords on your device.
  • activeTab – to find the tab you are viewing when you open the popup.
  • Host permission <all_urls> – required by webRequest to see the requests made on the websites you visit. It is not used to read or change page content.

Limited Use

The use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's features and is never sold, transferred, or used for advertising or creditworthiness purposes.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new "Last updated" date.
